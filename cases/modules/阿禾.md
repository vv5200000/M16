# 阿禾（ISFJ · 守卫者）

## 画像
- 1984 年生，猎庄南面山村人；老庄主贴身护工 18 年，生死包办。
- 说话轻声细语、动作极轻；记一本《照顾日记》十八年没断过。对"名字"和"钥匙"有身体级回避（提到时手指微蜷）。死于忠心的那一种人——但忠诚本身就是两面的。

## 与案件关系
- 旧案碎片：2014 年协助庄伯年把陈望尸体转移至水塘（周敏走访记录实锤，见契约 §六）。
- 当晚机会/动机：近身照料、知柜门钥匙位置（庄主书房柜 = 凶器存放处）；案发当夜庄主清醒过一次，说了句"对不起"，她写在日记最后一页，没问"对不起谁"——因为她知道。

## 证据碎片
| 碎片 | 指向 | 归属路径 |
|---|---|---|
| 《照顾日记》最后一页："对不起" | 知情者 · A 强 / B 无 | 日记/信线 |
| 偷偷配了一把柜门钥匙，从未用过 | 能取凶器 · A 强 | 枪线（她知书房柜） |
| 配钥匙动机自述："万一他再需要开门" | 忠诚信号 · 双向可解 | 防反转碎片 |
| 2014 转移尸体的协助者（周敏记录） | 旧案执行者 · A 中 | 档案—沉默链 |
| 庄主病中反复念"陈望"，她记下又涂掉 | 知情隐瞒 · A 弱 | 日记/信线 |

> 防反转碎片：钥匙是"配了没用过"，日记写的是"对不起"不是名字——若 A 版作伪，可翻为"她只是替庄主保管，从未开过柜"。

## 嫌疑标签
- 主嫌疑 A（情绪背叛 · 主入口），物证 = 钥匙 + 日记。
- 反转余地：全程无第 2 人证她到过书房柜；B 版下她是"被嫁祸的忠诚者"（真凶借她的钥匙位置布线）。
