# P1 · 档案箱

> 节拍 P1：死亡报告 + 规矩表（新增行）。挂载：无（设定）。决策点：无，自由探索，关键词吸附。计分：S/N 感知，定罪不参与。

## 场景正文

档案箱是樟木的，角上磕了一处，锁扣是新的——换过。

2024 年 8 月底，猎庄老庄主死于自己召集的聚会。材料不齐，你要把它归档。

箱里的东西不多：

- 死亡报告一份，三联纸，第二联的复写淡得快看不见了
- 规矩表一页，卷在三夹板里，纸边发黄，四十年了
- 邀请函复印件一沓，原件不在材料里
- 空白录音带一盘，标签上只写了日期，什么都没录上
- 照片几张，大多拍糊了，最后一张只照到一只手

你把报告抽出来。纸很轻，盖章的红戳还没完全干透似的——

**死亡报告（摘要）**

| 栏位 | 内容 |
|---|---|
| 死者 | 庄伯年，猎庄第三代掌事 |
| 出生 / 死亡 | 1960 — 2024 年 8 月末夜 |
| 地点 | 山屋主厅 |
| 死因 | 枪击。唯一死因，无其他损伤 |
| 凶器（推定） | 猎枪一支，膛线八月间检修过；弹道比对结果待补 |
| 备注 | 枪响时，受邀者尚未到齐 |

*（弹道比对那一栏是空的。材料不齐——这就是你要归档的原因。）*

规矩表摊开在桌上。纸比报告重，也比报告旧。三代人传下来的东西，到他这一代已经是第四版：

**猎庄规矩（第四版）**

| 条 | 内容 |
|---|---|
| 一 | 猎什么：只猎山上的，不猎山下的。 |
| 二 | 不猎什么：不猎怀崽的兽，不猎雪天的脚印。 |
| 三 | 几点开灯：日落掌灯，鸡鸣熄灯。灯亮着，人才是在山下过夜的心安处。 |
| 四 | 谁可以进山：庄里的人可以；庄外的人，要庄主点头。 |
| 五 | **受邀者抵达后，不得擅自离开猎庄范围。** |

前四条字迹一致，是老庄主中年时一笔一画写的。第五条字迹相同，但墨色偏新——像是不久前才添的。规矩表没有"删"字，只有"添"。添的是一条从前的猎庄从来没有过的规矩。

照片里的那只手，指节粗大，虎口有茧，手腕上露出一截旧袖口。拍糊了，看不出是谁。

录音带是空白的。标签日期是 2024 年 8 月，其余无字。

## 决策点注

无。P1 为自由探索开场——读者先看报告还是先看规矩表、先查"枪"还是先查"第五行"，均作 S/N 感知信号采集（first-decision-wins），不计定罪。开场叙事只给一句"材料不齐，你要把它归档"，不引导任何优先顺序。
