## 正文格式契约（每拍文件统一结构）

1. **场景正文**——读者实际看到的叙事文本（档案文体，冷静克制）。
2. **词库表**——`| 关键词 | 同义词 | 返回文本块 | 映射 |`。
   - 映射只允许 **S / N**（感知层）；**严禁 T/F/E/I/J/P 入计**（一维一信号源铁律）。返回文本可用冷静语气，但语气词不产生任何维度分。
   - 决策层分叉（T/F·E/I·J/P）只发生在"读者自由输入行动词"的隐性分叉点，由行为捕捉，不在词库表回显。
3. **决策点注**——有则标注：`活动：XXX（计分流向）`。P1/P3 无决策点，P2 顺序信号。注释永不进入前台；注释内亦不得出现卡司总数。
