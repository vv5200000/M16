# P2 · 死者

> 节拍 P2：庄伯年小传、托付之网（表→老何 / 合同→陆况 / 陪护→顾言）。挂载：庄伯年。决策点：先看哪件托付（顺序信号，S/N 感知，不计定罪）。

## 场景正文

死者不是一开始就是死者。归档的第一步，是认识死者。

材料里有一份手写的生平，笔迹和规矩表同源——是老庄主自己写的，生前写的，墨色均匀，几乎没有停顿。

**庄伯年（1960—2024）**

猎庄土生土长。第三代掌事。十六岁能单手提枪，十八岁独自进山七天七夜——那是庄里老人至今还讲的事。

他订的规矩，全村守了四十年：猎什么、不猎什么、几点开灯、谁可以进山。说一不二，坐姿端正如钟。他就是规矩本身——村里没人恨他，但也没人敢爱他。做了四十年"说了算的人"，也因此四十年没朋友。

妻子早逝。儿子去了省城，再没回来。他一个人守着猎庄，把规矩当儿子养。庄里的老人说：庄主不缺人伺候，缺人说话。

三年前他病重，做了一些安排。材料里三件东西，对应他托付的三个人——**他把后事一件件安排给不同的人，每个人守一个位置，谁也不知道全局。**

**① 一只表**（托付给：修表的老何）

表是旧钢表，表带换过两次，表盘有磕痕。表壳可以旋开——里面似有夹层，档案照片只拍到旋开前的状态。夹层里有没有字条、写了什么，材料里没有抄录页，待核。

**② 一份合同**（委托给：城里的律师陆况）

合同草稿，落款处空着，没有签字。条款里有一条关于"死后安排"的段落，措辞是"无继承"——具体的权属内容被涂改过，看不清。这份文件没有完成，像是起草到一半，双方各存了心思。

**③ 一份陪护摘录**（来自：从省城来的顾言）

病重期间，由顾言负责陪护。归档的是几页事后整理的摘录，不是陪护原件：庄主病中反复念一个名字——字迹模糊处仅可辨「陈望」二字。末页有半句未写完的话，收尾处空着，像被打断。

三件托付，三条线：**表**通向那晚的时间，**合同**通向利益的底，**陪护**通向临死前没说出口的话。先看哪一件，随你。

## 决策点注

- 活动：先看哪件托付（表 / 合同 / 陪护）→ 顺序信号，S/N 感知计分（first-decision-wins），**不计定罪**。
- 三名受托人（老何 / 陆况 / 顾言）名字借"材料标签"形式出现，不展开人物画像——展开留到各自对应节拍（P5 老何的表与字条 / P10 顾言；陆况为浅挂材料，无独立深拍）。
- "陈望"与临终未写完的半句在此拍只露残页，不给"对不起"全文；全文与冲击留给 P9 沈知秋保险柜与 P10 顾言深水区。
