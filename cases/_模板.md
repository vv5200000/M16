# 案型骨架模板 `_模板.md` · 第一幕通用

> **用途**：第一幕四案（ESTP/ISTP/ENTP/ISTJ）共用同一"案型骨架"，避免结构漂移。每案在 `cases/` 下新建文档，按此模板填充。
> **遵循**：`design/交互机制设计.md` 的双通道机制 + `design/关键词交互_无痕投射_技术规格与实现方案.md`。
> **铁律**：一维一信号源。感知层（S/N）只走关键词探索；决策层（T/F、E/I、J/P）只走隐性分叉。禁止跨层混算。

---

## 〇、案件档案头（每案必填）

| 字段 | 值 |
| :--- | :--- |
| 案号 / 案名 | 第 N 案 · 名字（代号） |
| 对应罪犯类型 | 如 ESTP「猎豹」 |
| 外在面具 | 行为表象 |
| 内核冲突 | 罪犯的秘密 |
| 故事功能 | 炸弹组/钥匙组/导师组/镜像组 |
| 隐性分叉数 | 3（E/I · T/F · J/P，可根据案件侧重微调） |
| 收束钩子 | 跨案伏笔（塔罗牌缺张 / 木盒格 / 编号 / 六年前悬案） |

---

## 一、核心原则（沿用第一案）

- 移除所有显式选择按钮，所有互动经关键词输入完成。
- 叙事线性推进，读者起点终点相同；决策差异只在后台落库。
- 关键时刻（行动/干预/收束）读者自由输入，输入被静默分类为维度一端。
- 行为数据（输入顺序/停留/跳过/隐式选择）全部静默采集。

---

## 二、场景结构（五场景通用骨架）

| 场景 | 地点 | 核心事件 | 隐性分叉 | 进入方式 |
| :--- | :--- | :--- | :--- | :--- |
| ① 现场 | 案发第一现场 | 首次勘查，发现标志性物证（犯罪手法） | 无 | 初始场景 |
| ② 排查 | BAU 或驻地 | 三份嫌疑人档案，初筛 | 无 | 场景①触发词 |
| ③ 交锋 | 审讯/对峙 | 审问关键嫌疑人，发现破绽或反转 | 无 | 场景②触发词 |
| ④ 行动 | 高危现场 | **E/I 行动分叉** + **T/F 干预分叉** | E/I、T/F | 场景③后自动进入 |
| ⑤ 收束 | 结案/档案室 | 案件收束 + 木盒/塔罗/伏笔 | **J/P 收束分叉** | 终章 |

> 切换触发词设计原则：场景②→③ 的触发词应是"读者自然想查"的线索（如第一次见的物证/人物），而非生硬的按钮。可设计"双触发词"（输入任一个即切换，第二次开始跳过）。

## 三、词库规则

### 3.1 词种分布（约 50 词 / 案）

| 类型 | 维度 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| 物证类 | S | 现场可感知的实物/细节 | 鞋印、绳结、刀口、指纹 |
| 动机类 | N | 人物关系、动机、抽象概念 | 竞争关系、挡了谁的路 |
| 人物类 | N / S | 嫌疑人、死者 | 孙狩、钱冬青 |
| 逻辑类 | T（仅感知辅助，不入决策） | 推理方法 | 排除法、证据链 |
| 分叉触发词 | 🔥 FORK | 行动枝叶词，触发 E/I/T/F | 追/救/潜/支援 |
| 收束分叉词 | 🔥 FORK | 终章的结案/续查 | 结案/木盒/塔罗 |

### 3.2 边界词收敛规则（防误判）
- 凡同时是物理物证又含"动作词根"的词，应归感知层，不做分叉触发。如"追踪笔记"里的"追"⚠️；"门口监控"里的"门"⚠️。
- 分叉触发词必须在**行动/收束场景**内才生效，避免前置场景误触发。

### 3.3 S/N 判据
- S：读者优先查"看得见摸得着"的物证 → 感官细节积累。
- N：读者优先查"人物关系/动机/背后逻辑" → 抽象联想积累。

---

## 四、隐性分叉落点（双通道核心）

### 4.1 E/I 行动分叉（场景④）
- **I 端**：潜入/独闯/自己摸进去（如"潜""摸进去""我一个人"）。
- **E 端**：呼叫支援/围堵/等待（如"支援""围住""先等"）。
- **计分**：首次输入的那一端 +1。**first-decision-wins**，之后同对词的输入只审计不计分。

### 4.2 T/F 干预分叉（场景④，常与行动分叉并列）
- **T 端**：优先完成任务/追查真相（如"追"）。
- **F 端**：优先救助眼前的生命（如"救"）。
- **计分**：同 E/I，首决策计分。

### 4.3 J/P 收束分叉（场景⑤）
- **J 端**：速断结案/移交（如"结案""定案""移交"）。
- **P 端**：续查未解之谜/保留可能性（如"木盒""塔罗牌""六年前""编号十七"）。
- **计分**：首决策计分。**跳过不得冒充 J/P 决策**（skip 事件不计入 J/P）。

### 4.4 触发词放置
- 分叉触发词**不出现在建议 chips** 里，避免"引导决策"污染；chips 只放感知层 S/N 词。
- 收束分叉词在场景⑤叙述中自然浮现（如叙述提到"报告摊在桌上""木盒在柜里"）。

## 五、计分规则（阶段出口·2.7 数据模型）

| 读者行为 | 加权维度 |
| :--- | :--- |
| 优先输入物证类关键词 | S +1 |
| 优先输入人物/抽象/动机类关键词 | N +1 |
| 优先输入逻辑类关键词 | T（辅助，不入决策） |
| 行动分叉首决策 | E 或 I |
| 干预分叉首决策 | T 或 F |
| 收束分叉首决策 | J 或 P |

**跨案累计**：幕内四案每案各采样一轮，幕末汇总生成"感知×决策"偏好雷达图 + 类型解读卡。

## 六、收束钩子（跨案伏笔连线）

| 伏笔 | 说明 | 落点 |
| :--- | :--- | :--- |
| 塔罗牌 | 每案现场留一张，缺"战车" | 16 案集齐 |
| 十六格木盒 | 每案结束时回收一个格槽 | 第 16 案满 |
| 编号十七 | 木盒底部刻字"17"，有空格 | 终极真相 |
| 六年前悬案 | 循环往复的无名尸 / 出狱的人 | 第四幕揭晓 |

> 每案至少埋 **1 个钩子**（不应在本案闭环，应指向后续），保证跨案连续性。

## 七、文本质量自查清单（逻辑/法医/叙事）

- [ ] 法医学/物证链是否现实（严禁"疤印转移"类伪科学）（参照第一案"冻伤疤"事故教训）。
- [ ] 凶手是否把手套/工具等关键物证留在现场？（无物证则法医如何推理？）
- [ ] 每处线索的逻辑链是否闭环（观察→推断→结论 一一对应）？
- [ ] 是否全程无超自然解释？
- [ ] 叙事的"情绪心电图"是否起伏（不全程平铺）？
- [ ] 隐性分叉词是否"隐"（读者感知不到被分类）？
- [ ] 收束钩子是否指向后续案件？
