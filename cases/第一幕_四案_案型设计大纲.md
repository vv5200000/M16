## 二、逐案设计

### 第 1 案 · 《猎杀营》 ESTP「猎豹」（方案 B 重写）

| 项 | 设计 |
| :--- | :--- |
| 外在面具 | 真正的野外猎杀者：追踪猎杀单独进山的背包客，享受猫鼠游戏（非产业链老板） |
| 内核冲突 | 脖颈挂一只老死金毛的骨灰吊坠——那是唯一让他"想停下来"的存在 |
| 犯罪手法 | 追踪 → 布杀 → 留"猎"字（狩猎印章），现场有狩猎仪式痕迹 |
| 现场标志 | "猎"字 + 猎刃/弓弩伤口 + 围猎足迹（鞋印） |
| 隐性分叉 | ④ 猎人营地/再猎现场：E/I 行动（潜/围）+ T/F 干预（救伤者/追凶）；⑤ 收束：J/P |
| 破案反转 | 追查中凶手因"护着一条狗的猎物"而第一次犹豫，暴露人性裂缝成为突破口 |
| 塔罗牌 | 留「愚者」（对应猎豹的猎人本能/出发） |
| 钩子 | 塔罗缺「战车」；六年前悬案；金毛死因与凶手"停下"的关联 |

---

### 第 2 案 · 《扳手》 ISTP「扳手」｜炸弹组 · 高能冲击

| 项 | 设计 |
| :--- | :--- |
| 外在面具 | 无动机随机杀人，纯凭感官冲动——手法精密的"纯粹感官罪犯" |
| 内核冲突 | 城市匿名救援队队长：只在灾难现场现身救人（白天救人的人 = 夜间随机杀人的人） |
| 犯罪手法 | 现场被"重新布置"成精密的机械装置（钟表/杠杆/引线），死亡呈现"作品感"，却无动机、无指向 |
| 现场标志 | 每个现场留一枚金属徽章（道具体系），徽章编号随案递增 |
| 场景骨架 | ①现场（装置残骸）→ ②排查（三份"无关联"受害者关系图）→ ③交锋（救援队目击者）→ ④行动（下一次"灾难"现场，救援队出勤 = 凶手在场，E/I·T/F 分叉）→ ⑤收束（木盒 + 徽章） |
| 反转 | 追查的"救援队长"身份，实为凶手自证"无动机"的伪装——他的随机杀人，恰恰是他唯一"允许自己停下救人"的方式 |
| 幕内职能 | 炸弹组 · 高能冲击（随机性制造幕内情绪顶点） |
| 钩子 | 徽章编号"2"；与塔罗牌"宝剑"意象挂钩 |

---

### 第 3 案 · 《小丑》 ENTP「小丑」｜导师组 · 巧思

| 项 | 设计 |
| :--- | :--- |
| 外在面具 | 模仿历史悬案，把犯罪当"智力脱口秀"——给警方留谜题、挑衅信、预告 |
| 内核冲突 | 房间贴满被撕碎又粘好的同一张凄美女人画像——模仿的每一案，都是"重演"某段无法放下的过往 |
| 犯罪手法 | 完美复刻三起著名历史悬案（降维替换成现实可作案的手法），并预告下一案 |
| 现场标志 | 每现场留一张塔罗牌（缺"战车"张），预告信带编号 |
| 场景骨架 | ①现场（历史悬案复刻的"签名"）→ ②排查（三案类比，发现复刻规律）→ ③交锋（接预告信，与之"对谈"）→ ④行动（第四起"预演案"，抢先行动，E/I·T/F 分叉）→ ⑤收束（画像碎片 = 内核冲突揭晓） |
| 反转 | 凶手"小丑"是当年那起"历史悬案"的受害者家属，他用复刻完成"替旧案翻案"，而非复仇 |
| 幕内职能 | 导师组 · 巧思（智力演示另一种"动机逻辑"） |
| 钩子 | 塔罗"战车"的意象；画像与"六年前"悬案联动（导师组间的"致敬"） |

---

### 第 4 案 · 《铁砧》 ISTJ「铁砧」（急转案）｜镜像组 · 指向主角

| 项 | 设计 |
| :--- | :--- |
| 外在面具 | 复刻小说情节杀人，惩罚"破坏城市旧貌的人"——规训式连环杀 |
| 内核冲突 | 黑市顶级身份伪造师，只帮家暴受害者"消失"——他惩罚破坏者，也庇护逃亡者 |
| 犯罪手法 | 每案按一本"经典悬疑小说"的章节行凶（现场布置成书中场景），预告对象是"城市改造者/开发商" |
| 现场标志 | 现场留一张手写"书签"，标注小说页码 |
| 场景骨架 | ①现场（书页场景复刻）→ ②排查（受害者均为城市改造相关，发现"小说地图"）→ ③交锋（追查伪造身份网络，牵出庇护线）→ ④行动（下一个改造点，E/I·T/F 分叉）→ ⑤收束（木盒 + 重大反转） |
| 反转 | **幕末急转**：第 4 案真凶在抓捕时"顶替"了一个受庇护者身份 —— 引出主角团内部：谁在漏报？结合木盒第 4 格 = "空"（第一幕收尾钩子） |
| 幕内职能 | 镜像组 · 急转（直指主角团人格，收幕 + 埋主谜题钩子） |
| 钩子 | 木盒第 4 格为空 + "编号十七"伏笔；主角团内部信任危机（进入第三幕"内乱"的种子） |

## 三、分叉落点汇总（确保四案四维全覆盖）

| 案 | E/I 落点 | T/F 落点 | J/P 落点 | 幕内职能 |
| :--- | :--- | :--- | :--- | :--- |
| 1 猎豹 | ④潜/围 | ④救伤者/追凶 | ⑤结案/木盒塔罗 | 幕首示范 |
