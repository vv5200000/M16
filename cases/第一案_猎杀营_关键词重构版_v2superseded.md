# 第一案 · 猎杀营（关键词版 · 正式版）

> 本文档是「MBTI 16型人格 · 罪案侧写互动叙事」第一案《猎杀营》的正式版本。
> 基于“关键词交互·无痕投射”交互形态，采用**感知层×决策层双通道**：S/N 走关键词探索，T/F、E/I、J/P 走隐性分叉。
> 配套规格见 `design/关键词交互_无痕投射_技术规格与实现方案.md`。旧显式分叉版见 `cases/第一案_猎杀营_分叉版_superseded.md`。

## 一、整体思路

### 1.1 核心原则
- **移除所有显式选择按钮**：不再出现“A/B/C”或“你选谁”的选项。
- **所有互动通过关键词输入完成**：读者输入他想查看的人、物、线索或概念，系统返回对应的剧情文本块。
- **叙事线性推进**：故事线性展开，不因读者输入产生可见分支。所有读者的起点和终点相同。
- **决策层保留为隐性分叉**：关键时刻（火场/收束）读者自由输入，系统在**后台**把输入分类为 T/F、E/I、J/P 的一端并落库——读者感知不到分支，但"决定"已记录。
- **心理路径差异化**：不同读者因关注点、决策不同，产生完全不同的心理轨迹。
- **行为数据采集**：输入顺序、关注对象、忽略内容、隐性分叉选择，全部静默记录，用于生成人格偏好雷达图。

### 1.2 与《项目圣经》的关系
- 《项目圣经》定义了：世界观、16罪犯人设、16案叙事总纲。
- 本文档定义了：第一案的**场景结构**、**每幕叙事文本**、**关键词词库**、**场景切换条件**、**隐性分叉落点**。
- 本文档是《项目圣经》中第一案部分的**可执行细化版本**。

### 场景① · 现场

#### 叙事文本（初始锚点）

雨下了整整三天。M市郊野公园的泥土泡成了一锅暗红色的稀粥。

我蹲在警戒线边缘，雨衣兜帽压得很低。雨水顺着帽檐滴在膝盖上，渗进裤管，凉得像一条蛇顺着小腿往下爬。更难受的是手套——湿透了，指尖泡得发白，每一次握拳都能挤出冷水。

手机震了。陈默发来一行字：*“看完了？什么想法。”*

我没回他，掀开帐篷帘。法医老周冲我点点头，挪开身子。

死者男性，三十五岁，户外冲锋衣，登山靴。右手被登山绳吊在横杆上，整个人跪着。致命伤在颈侧，一刀割开颈动脉，利落得像是外科手术。

但让我僵住的，是他的左手掌心。那里被人用记号笔写了一个字：

**“猎”**。

法医老周把尸检报告递过来，用笔尖点着报告上的关键处：“刀口从左向右，右撇子。深度一致，没有犹豫。死者体内没有毒素，胃里是几小时前吃的夜宵——出门前他吃过东西。”

“像是赴约。”我说。

老周点点头：“像是赴一个他认为很安全的人的约。”

我重新看向那个“猎”字。雨水从帐篷缝隙里溅进来，落在掌心上，那个字被浸得微微发胀。我盯着它看了很久。

### 场景② · BAU办公室

#### 叙事文本（场景切换）

从现场回来，我在BAU办公室的桌前坐下。三份档案摊在面前——赵远山、钱冬青、孙狩。

陈默站在窗边，背对着我：“这三个人，你觉得谁？”

我拿起第一份档案。赵远山，四十七岁，前动物园驯养员，擅长麻醉枪和绳结，因违规麻醉保护动物被开除。食指伤残，神经坏死。

第二份，钱冬青，三十八岁，西北籍冷库搬运工，左手指甲缝常有戈壁沙土，手上有冻伤疤。有持刀威胁前科，但案底显示——他见血就晕。

第三份，孙狩，二十九岁，户外兼职领队。和陆征有竞争关系，手上茧厚，会绳结。案发当晚在酒吧，有三人作证，体重六十五公斤。

我把三份档案合上，靠在椅背上。

“都有矛盾。”我说，“赵远山的笔迹对不上，钱冬青的心理对不上，孙狩的物证对不上。”

陈默转过身来：“所以？”

“所以，”我看着他，“还有一种可能——这三份档案，是有人故意摆给我们的。”

陈默没说话。但他的眼神告诉我，他想的一样。

### 场景③ · 审讯室

#### 叙事文本（场景切换）

我选了孙狩。

不是因为他最像凶手——是因为他坐在审讯室里那副“我已经准备好了”的表情，让我觉得不对。

审讯室的灯亮得刺眼。孙狩坐在对面，双手放在桌上，十指交叉，姿势放松得像是来喝咖啡的。

“你认识陆征多久了？”

“四年。”他答得很快，“跟他一起带过队，后来分开带。”

“分开的原因？”

“他做高端线，我做普通线。他比我稳，客人更喜欢他。”他说这句话的时候，嘴角带着一点笑，像是在说一件早就消化完的事。

我看着他。他没躲。

“昨天晚上你在哪儿？”

“酒吧。四个人，喝到两点。小票有，人你也能去问。”他微微前倾，“我听说陆征死了。你们找上我，我没意见。但我跟他的关系，没到要杀他的程度。”

他顿了顿，补了一句：“陆征这个人，真正让人想杀他的，不是他的竞争对手，是他挡了谁的路。”

我看着他的眼睛。他说完那句话之后，抿了一下嘴唇——嘴唇是干的。一个放松的人，不会在说完话之后下意识舔嘴唇。

他在紧张。他在紧张什么？

### 场景④ · 冷库

#### 叙事文本（场景切换）

凌晨两点，关氏冷链物流仓库，M市郊区。

暴雨变成了冰粒，砸在铁皮屋顶上像撒了一把钉子。我蹲在仓库北侧的排水沟边，看着那辆厢式货车就停在装卸口——就是监控拍到的那辆。驾驶室的门半开着，副驾扔着一副溅了泥的登山靴。

手机又震了一下。技术室发来第二份比对结果：那副靴子的鞋底纹路，和凶案现场“来和回”的鞋印，完全吻合。

我抬头看了一眼仓库二楼。有一扇窗户亮着灯。

耳机里传来陈默的声音：“支援二十分钟到。你等还是进？”

我没有回答。冷库的氨气管道在冰粒里发出低沉的嗡嗡声，像是某种动物的呼吸。那扇亮着灯的窗户后面，有一个人影在移动。

然后我听见了另一声。

不是嗡鸣声。是人的喊声，从仓库北角传来的，闷闷的，被铁门堵住的那种：

“有没有人——救命——！”

是小满。今天白天在技术室整理关氏冷链出货单的那个实习生。

火是从装卸口内侧烧起来的。浓烟从仓库门缝里涌出来，冰粒打在黑烟上，像在翻炒一锅焦炭。

二楼的灯灭了。一个高大的黑影从装卸口里走出来，手里拎着一个汽油桶，头也不回地朝雨中走去。

**（隐性热点 · 行动方式 E/I）** 陈默那句"你等还是进"还在耳机里。你打字框里没有选项——你输入"潜入""摸进去""自己"是独行（I 端）；输入"支援""等陈默""围住"是联动（E 端）。系统不判断对错，只记下你倾向于哪种打法。**（叙事视角无需向读者解释；本行括号内容仅供实现，读者端隐藏。）**

**（隐性热点 · 火场抉择 T/F）** 火、铁门里的小满、走向围墙的黑影，三条线压在同一秒。你输入"追""抓""汽油桶"是任务端（T）；输入"救""门""小满"是人端（F）。剧情无论哪端都线性收束，但收束文本会给你一句不同的回响。

### 场景⑤ · 收束

#### 叙事文本（场景切换）

——无论你当时走向了哪个方向，火最终是扑灭的，人也是被抓住的。只是代价不同。

关震海被铐上警车的时候，没有反抗。他坐在后排，头靠在车窗上，像是在等一个等了很久的结局。

结案清点他的保险柜时，技术员在里面找到了一个木盒。十六个格槽，里面只放了两样东西：两副塔罗牌。其中一副缺了一张。

缺的那张是「战车」。

陈默站在保险柜前看了那个盒子很久，忽然开口：

“这是第二副了。”

我看着他。

“六年前，有一桩无人认领的悬案，”陈默的声音很轻，“证物袋里也有一张塔罗牌。也是战车。”

他划开手机，翻出一张加密旧卷宗的照片。照片里的证物袋，静静地躺着一张「战车」。

我低头看着那个木盒。十六个格槽，只放了两个东西。一个是现在的关震海，一个是六年前的……

窗外的雪，在凌晨三点下得更大了。

**（隐性热点 · 收束方式 J/P）** 案子到了该画句号的时候。打字框里没有"结案/续查"按钮——你输入"结案""报告""定案""移交"是速断端（J）；输入"木盒""六年前""格槽""编号十七""塔罗牌""陈默"是续查端（P）。你停在盒子前多看的那几次输入，就是你在"保留多解"。**（叙事视角无需向读者解释；本行括号内容仅供实现，读者端隐藏。）**

### 维度映射权重参考

> 原则：**一维一信号源**。感知层只计 S/N，决策层只计 T/F、E/I、J/P。不得从感知行为反推决策维度。

**感知层（S/N，按输入顺序与覆盖度加权）：**

| 读者行为 | 加权维度 |
| :--- | :--- |
| 优先输入物证类关键词（猎字、鞋印、绳结、货车、氨气管线） | S +1 |
| 优先输入人物/抽象类关键词（孙狩、关震海、动机、挡了谁的路、六年前） | N +1 |
| 优先输入逻辑类关键词（排除法、冲突点、证据链、施压） | T（仅感知辅助，不入决策层） |

**决策层（T/F、E/I、J/P，仅由隐性分叉产出）：**

| 隐性分叉 | 触发词分类 | 产出端 |
| :--- | :--- | :--- |
| 行动分叉（场景④·仓库） | 潜/摸进去/自己 → I；支援/围住/等 → E | E / I |
| 干预分叉（场景④·火场） | 追/抓/跟上 → T；救/门/破门 → F | T / F |
| 收束分叉（场景⑤·收束） | 结案/定案 → J；木盒/六年前/塔罗牌/编号十七 → P | J / P |

> **不再使用**「跳过次数多→J」「探索面广→P」等代理映射——那会把"效率偏好"误当"判断偏好"。
