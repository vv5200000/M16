# v2 · 16 人物故事线（人物小传 · 第一稿）

> **定位**：后台素材库。16 篇人物小传 = 16 个人格画像的独立人生故事。前台叙事从中取材，按需裁剪、安排节奏、控制读者获知的顺序与深度。
> **人格代码**：仅后台标注，读者文本永不点破。
> **嫌疑标签**：初步意向（A=情绪背叛型 / B=冷算布局型 / C=冲动误杀型），待案件契约定稿后复核。
> **本文档性质**：所有内容为已知事实全集。悬念由前台叙事层制造，小传本身不留悬疑。

# 苏晚（INTJ · 建筑师）

苏晚十二岁那年第一次听到"账"这个字的全部重量。

腊月里债主上门，父亲站在门口一言不发，母亲在屋里数钱——数了三遍，差两块。债主说"过完年再说"，转身走了。苏晚记住了母亲数钱的样子：三遍，每遍都一样，但母亲还是数了第三遍。

那年她学会了一件事：所有重要的事，都要数三遍。

县农机厂八级钳工的女儿，全县第一考上省城大学金融系。大二那年发现导师论文里的模型有系统性误差，她自己改了重跑，把结果交给导师。导师把论文署了自己的名字。她没闹，只是从那天起，所有真正重要的计算都不再经人手。

2008 年金融危机前三个月，她重仓做空某银行股。全公司以为她疯了。她写了三十页《如果错了，我错在哪》，每一页都假设自己错了，然后逐条推演"错在哪里会导致什么结果"。三十页写完，她确认自己没有错。一战封神。她对外从不说"我赌对了"，只说"我算对了"。

丈夫是大学同学，追了她七年。婚后她几乎不回家。丈夫习惯了一个人过年，习惯了她的沉默，习惯了在她三页复盘写完之前不去打扰。三年前丈夫出差途中车祸身亡，肇事者至今未找到。她赶到医院时人已经没了，她在走廊站了一夜，第二天把保险理赔、肇事者资料、医院账单、法医报告全部编号归档，做成一个文件夹。从此每年忌日只打开那一个文件夹，看一遍，合上。她没哭过，至少没人见过。

但没人知道的是：她私下雇人追查肇事者两年，线索断在猎庄附近。她没有继续查下去——不是不想，是线索指向的那个人，和二十年前她第一桶金的来源，是同一个地方。

二十年前，五万块现金经一个中间人从猎庄账上流转到她手里。这笔钱改变了她的一生，也一直是她心里的一个"未结项"。二十年来她从没追过它的来源——因为她知道，有些账追下去会咬人。

三个月前，猎庄账本上那笔对不上号的现金流出现异动：有人开始动用这笔钱。她决定回猎庄，查清那个数字。

她的房间里只有三样东西：一台电脑、一本锁起来的账本、一张写满数字的纸条。纸条上是猎庄周边三处房产的购地时间，每一处都对应着她第一桶金的某个节点。

她说话前永远先沉默三秒。不解释，不寒暄，不说废话。被问及丈夫时用"那件事"代替。整理文件时强迫症般编号。

她回猎庄不是为了吊唁，是为了一个数字。

# 顾言（INFJ · 提倡者）

顾言十二岁那年，父亲进山再没回来。

全村找了一个月，只找回一把枪。枪搁在山神庙门口的台阶上，像一个人放下了什么东西就走了。母亲从那天起常去山神庙，一坐就是一下午。顾言从此学会了一件事：听人把话说完。

师范毕业后做了三年小学教师。班上一个孩子被家里打，他拦了一次，被家长举报"多管闲事"，调离。他从那天起明白：有些人不是不知道道理，是没人愿意听完他们的话。

辞了教职，去省城临终关怀医院做护工，一做八年。他的工作准则只有三条：不评价、不劝、不改变。病人临终前愿意把秘密留给他，因为他从不往外说，也从不评判。他记得每个病人的一句话，却从不在病历上多写一个字。

他照顾过的病人里，有三个死于"意外"。三家的家属都松了一口气。他从没被人问过当时在不在场——因为他总在半夜独处时守在床边。他没做过什么，但他清楚地知道：那三个老人死的那晚，他在房间里，听到了他们最后的呼吸。

三年前老庄主点名要他回来陪护最后一个月。他回来那天庄主还精神矍铄，不像将死之人。庄主叫他"小顾"，像叫一个还欠着家的人。他陪护的那个月里，庄主整夜不睡，反复念一个名字。他没听清那个名字——或者说，他听清了，但选择不去记。

庄主弥留时对他说了句"对不起"。没指明对象。他将这句话记在心里，未对任何人说过。

他离开猎庄后，每月十五号给山神庙寄一笔无名捐款，从未留名。寄了多少年，他自己数过，但没告诉任何人。

他能总在别人最乱的时候出现，递一杯温度刚好的水。说话前先确认对方"要不要说"。从不说"我认为"，只说"你愿意讲讲吗"。对"名字"异常敏感——如果有人在他面前提起某个名字，他的手会微微停顿，很轻，像一个还没按下就被收回的音符。

他没有秘密——或者说，他的秘密是：他什么都听见了，但他选择不说。

# 江迟（INFP · 调停者）

江迟从小在后台长大。

父亲是省城话剧团的舞美，母亲是电台播音员。他记得小时候坐在幕布后面看台上的人演戏，台上演的是生离死别，台下观众哭成一片。他不哭——他知道那是假的。但他记得母亲的声音从收音机里传出来，说"这里是午夜节目"，然后念一首诗。那个声音是真的。

大学读中文系，写小说，毕业那年父亲病逝。他把所有稿费用来给父亲办了一场没人来的"首演"——空荡荡的话剧厅，他一个人坐在台下，看父亲生前画的布景在幕布上亮了一分钟，然后灭了。那是他人生里最安静的一分钟。

自由编剧，写过两个没上映的剧本，一个没人看的连载。夜里在酒吧驻唱，歌词总藏着一层别人看不懂的意思。他说那是"留给懂的人的门票"。他不在乎数据，在乎"有没有人真的听懂了"。

交往两年的女友半年前失踪，警方定性为"离家出走"。他不信。女友失踪前三天，让他改掉一首歌的一句歌词——"天亮之前，别回头"——理由是"唱出来不吉利"。他改了，但把原词偷偷留了下来。

女友失踪后，他停了所有连载，只剩夜里那把吉他。他每天去酒吧唱同一首歌，唱到"天亮之前，别回头"那句就停。不是故意的，是嗓子到那里就哑了，像被什么东西卡住。

三个月前，有人寄给他一张票。票上印着的正是那句被改掉的歌词。他没查寄件人——因为他知道，知道那句歌词的人，除了他和女友，只有一个人：他女友失踪前曾提过的那个"在猎庄见过的人"。

他口袋里一直放着那张票，票根被揉烂了，他还留着。

他父亲年轻时在猎庄画过布景，他小时候去过一次猎庄。那次的记忆他几乎全忘了——除了山神庙墙上的一幅画。画里有两个人，其中一个的轮廓不像猎庄人。

他说话像写歌词，句句有隐喻。对"不合时宜的话"记忆异常精准。紧张时反复摩挲那张票。唱到某句词一定停。

他这次回猎庄，是来找一个人——或者说，是来找一个人消失的真相。

# 孟慧（ENTJ · 指挥官）

孟慧从十六岁起就知道一件事：家里的事，她说了算。

1970 年生，猎庄北面矿业小镇。父亲是矿上调度员，母亲是缝纫社裁缝。家中长女，弟妹三个，她从小承担"主事"角色。别人家的孩子在玩泥巴的年纪，她已经在帮母亲记账、帮父亲跟矿上的人打交道。矿上的调度员老婆生了四个孩子，最小的那个最像个大人。

省城纺织厂会计出身。1988 年下海，做服装、做地产、做矿业，二十年没输过一局。她的信条：不在别人问问题的时候回答问题，要在别人还没问的时候给出答案。她赢在"提前三步"——在所有人还在解释问题的时候，她已经在安排善后。

集团做到省里前三。她开会从来不让别人把话说完——因为她已经知道答案。下属怕她，同行敬她，媒体叫她"铁娘子"。

她唯一没算到的事，是十年前的合伙人陈建国。陈建国跟她打天下二十年，是集团副手。十年前因一起矿难事故被追责，跳楼自杀。跳楼前留下一封只给她的信。

她接手了那封信，锁进保险柜，再没打开过。矿难的善后，她处理得滴水不漏——买断所有媒体报道，补偿受害者家属，完成矿权谈判。善后干净得像没发生过。但总有人记得：那天她到场时，脸上没有一丝慌张。

陈建国的女儿后来自杀了。孟慧没去葬礼。

猎庄地下的矿脉，是十年前那起矿难的矿权所在地。她一直没卖，也一直没动。三个月前，有人用那封信里的一个细节约她来猎庄谈"一笔永远不亏的买卖"。能读得懂那封信的人，只可能是当年知情的人。

她一开口别人都闭嘴。开会不让人把话说完。被问及陈建国时先说"那是十年前的事了"。对"当年在场的人"这几个字有本能反应——瞳孔会微微收缩，像一只突然被光照到的猫。

她这次回猎庄，是为了那封信——也是为了那个约她来的人。

# 陆况（ENTP · 辩论家）

陆况七岁就敢跟大人辩论"为什么我不能吃糖"。

父亲是县法院退休法官，母亲是中学语文老师。他从小在法庭旁听席上长大，知道每一个证据链都有一个"最脆弱的环节"——那个环节不是物证，是人。人会翻脸，人会撒谎，人会在最不该说的时候把话说出来。他从七岁起就知道这件事。

省城律所合伙人，专做并购与刑事辩护。他的风格：接案前先列"这个案子的所有坏角度"，再决定要不要接。他能把黑的说成白的，再花十分钟反悔——因为他说"角度要对，立场要活"。同行讨厌他，客户离不开他。他的职业本能是"如果对方翻脸，我手里有什么"——他记得在场每个人的一个把柄。这不是病，是习惯。

他坦率承认："我就是个卖角度的人。"

老庄主生前最后委托他起草一份合同。合同中有一处条款，连庄主自己都没发现——"如果庄主死了，什么都不会被继承"。陆况起草时故意留了这手：不是害庄主，是给自己留一个换钱的筹码。他知道庄主迟早会死，也知道这份合同在他手里，比在庄主家人手里值钱。

他复印了一份，藏在山神庙壁画后面。他知道阿朵常去补壁画，但阿朵看不懂合同——她只看得懂颜色和轮廓。

他还是孟慧集团的常年法务顾问。陈建国矿难善后，经他手处理。他掌握当年没销毁的部分文件——那些文件足以让孟慧坐立不安，也足以让他在任何谈判桌上多一张底牌。

他动过周敏的档案柜。抽走了庄主那一页。周敏知道是他干的，但没揭发——他们之间有一种"你知道我做了什么，我也知道你知道"的默契，谁也不先开口。

大学同学周敏，他动过她的档案柜；商场旧识苏晚，他见过她丈夫车祸后的归档文件夹；合伙人孟慧，他手里有她矿难的底牌。他在场的每个人都握着一张牌，而他的牌最多。

他十分钟内能把黑的说成白的，再花十分钟反悔。开口前先环视全场找"下一个要说服的人"。被问及合同时先说"还没定稿"——因为他要等一个"对方翻脸"的瞬间，好让这个筹码值最大价钱。

他这次回猎庄，还没决定要不要把那份合同拿出来。他在等一个时机——等一个"所有人翻脸"的时机。

# 沈知秋（ENFJ · 主人公）

沈知秋认识猎庄每一个人。

1980 年生，猎庄本地人。父亲是老庄主的猎友，母亲是村小的代课老师。她从小在庄子里长大，记得每家每户的难处——谁家孩子多、谁家欠着债、谁家老人病了看不起。她不是刻意记的，是"听了就忘不掉"。

师范毕业回村，做了猎庄中学校长，至今十年，没一个孩子辍学。她的方法不是劝学，是"先记住每个孩子家的情况，再决定怎么跟家长开口"。她能让最沉默的人说话——因为她先交付信任。她认识庄里每一个人，也因此掌握全村人的秘密。她从不主动用这些秘密，但她清楚地知道：谁软弱，谁靠得住，谁在撒谎。

她人生里唯一一次没按规矩做的事，是十年前。

那年一个学生溺死在猎庄的水塘里，校方定为意外。她签字认了。签字那天老庄主"恰好"去县里开会，不在庄里。她后来核对过庄主的行程记录，发现记录是补的——有人替庄主补了一张不在场证明。她没查下去，因为她怕。她怕查出来的真相，比"意外"更难承受。

那个学生的母亲，一年前自杀了。自杀前给她寄过一封信，她没拆，但也没扔。她把信留在校长办公室的保险柜里，像留着一个定时炸弹。她知道信里大概会写什么——但"大概"和"确定"之间隔着一条线，她不想跨过去。

今年水塘又淹了一个人。第二个溺亡者出现。她被迫直面十年前的那个签字。

她先问"你最近怎么样"再谈正事。记得所有人的难处。被问及溺亡案时说"都是十年前的事了"。对"水塘"两个字有轻微回避——不是刻意的，是身体先于意识做出的反应，像手碰到烫的东西会缩回去。

她知道顾言回来陪护过庄主，知道周敏经手过走访记录，知道阿禾提过庄主念名字的事。她知道的比大多数人多，但她选择把这些知道藏在"先问你最近怎么样"后面。

她是猎庄里唯一一个"所有人都信任的人"——也因此，是唯一一个"所有人都在等她开口的人"。

# 林一（ENFP · 竞选者）

林一从小就知道一件事：记下开心的，不开心的就慢慢淡了。

1995 年生，猎庄南面镇上。父亲早逝，母亲改嫁，由奶奶带大。奶奶是庄里的老裁缝，给他做了一柜子衣服——他长大后才懂，那是奶奶怕他"露怯"。别人家孩子穿旧衣裳，他穿的是奶奶连夜赶出来的新衣裳，针脚细密，像怕被人看出什么来。

自由摄影师，拍婚庆、拍全家福、拍山村纪录片。他的照片永远拍得比当事人开心——因为他相信镜头能留住最好的那一刻。他给庄里每个人都拍过一张照片，相册里有三千张笑脸。这是他的"快乐档案"，也是他的铠甲。

没人见过他哭。他的笑是职业本能，也是自我保护——就像奶奶给他做的新衣裳，是用来遮住什么的。

老庄主请他拍过一张全家福——庄主家唯一一张全家福，也是庄主最后一次笑。庄主家人后来要过三次，他以"还没修好"为由拖着。他没修，也没交付。不是修不好，是他觉得那张照片不该现在给出去——他说不清为什么，是一种直觉，像猎人闻到风向变了。

最近三个月，他在拍一组没人见过的照片：同一个角度、同一个门口，每天一张，风雨无阻。他给它起名《十三》。起因是连续三个清晨，他在同一扇门口看到一个"不该出现"的人。第十三张，拍到了那个人，也拍到了门口阴影里"另一个人"——两张脸，他都认识。

他还没决定给任何人看。

他拍照时永远笑着。说话快、语速急、喜欢打岔——因为"慢下来就会想太多"。被问及《十三》时说"还没修好"。相机从不离身，睡觉也放在枕边。

他三千张笑脸里藏着三千个秘密——每个人笑的时候，他在镜头后面看到的，是笑容底下那层别的东西。他说不清那是什么，但他记得。

他这次回猎庄，是来交那张全家福的——或者说，是来决定那张照片该不该交出去。

# 何钟（INTP · 逻辑学家）

何钟十一岁就会拆装一只表。

父亲是猎庄唯一的钟表匠，母亲是赤脚医生。他从小在钟表油的气味里长大，五岁趴在父亲的工作台上看齿轮转，七岁问父亲"为什么时间只能往前走"，父亲没答上来。他从此自己找答案。

十六岁接父亲的班，做了二十五年。猎庄三代人的表都经过他的手：有人拿爷爷的怀表来修，有人拿刚买的电子表来问"为什么不准"。他的回答永远一样："表没有坏，是你没给它上弦。"

他修表不修人。他能凭走时偏差判断一块表的主人摔过几跤、熬过几个夜。他说："齿轮不会撒谎，人会。"他看不懂人为什么撒谎，也懒得懂。

三年前老庄主托付他一块表，说"等我走了再打开"。表壳里藏着一张字条，字条上写着庄主"意外死亡"前两小时的时间，并附一句话："两小时，够所有人赶到。"

何钟看过了。字条上不只是时间，还有这句话。他对所有人说"还没看"——因为他想知道谁会来问这块表。如果有人来问，他就知道那个人是来"确认"的，不是来"打听"的。确认和打听之间差着一层意思：确认的人知道得比他说的多。

他修过顾言照顾的三个"意外"病人家的钟。三个钟停的时间，他都记得。三个时间差着几小时，但误差规律一样——像是有人在差不多的时间段里，做了差不多的事。他从没对人说过这件事，因为"齿轮不会说话，但会记录"。

他是庄里唯一能在夜里听出"枪响是哪种枪"的人。昨夜他听到了一声枪响，听得出是哪把枪。但他对所有人说"我睡得很沉"——因为"在场"和"没在场"之间差着一层意思，他不想被归到任何一层里。

他隔壁铺子是猎枪匠老孟头。两人是酒友，也是庄里"最不会撒谎的两个人"。他们之间有一种默契：让东西自己说话。老孟头修枪，他修表，枪和表都不会说谎。

周敏的办公钟就是他修的，每天慢四秒。他记得。他记得所有修过的钟，记得每一块表的主人。

他说话简短、惜字如金。修表时不许人打扰。被问及字条内容时说"表还没到打开的时候"——但他的眼神会微微移向庄主的方向，像是在等一个"已经打开的时候"。

他这次回猎庄，带着那块表。他还没决定要不要把它拿出来。

# 周敏（ISTJ · 物流师）

十年前溺亡案的走访记录，是她经手的。记录里有一个人，她认识——认识到不用看名字就知道是谁的程度。她从没告诉沈知秋。不是不想说，是"说出来的后果比不说更大"。

她不信人信档案，但她这一次隐瞒了两件事：陆况抽走的档案，和走访记录里的那个人。这两件事加在一起，是她三十年职业生涯里唯一的污点。

她这次回猎庄，是来确认那两件事的——确认档案被抽走后发生了什么，确认走访记录里那个人现在在哪里。

# 老庄主（ESTJ · 总经理）

妻子早年病逝，儿子去了省城再没回来。他一个人守着猎庄，把规矩当儿子养。庄里的人说：庄主不缺人伺候，缺人说话。

2007 年猎庄发生过一件事。那件事之后，他定下一条规矩："猎庄范围内，谁也不许再提起 2007 年。"那条规矩写在规矩表的最后一行，字迹比前面的都重，像是刻上去的。

三年前他病重，做了几件事：把表托付给何钟，说"等我走了再打开"；把合同委托给陆况起草；把陪护交给顾言。他把后事一件件安排给不同的人——像一个将军在布置战场，每个人守一个位置，谁也不知道全局。

三个月前他在规矩表最后加了一行禁令，然后请十六个人到山屋"宣布大事"。他请的人里有他的债主、他的旧敌、他的恩人、他的秘密。十六个人，十六种关系，十六个他欠过或欠过他的人。

账本上有一笔对不上号的现金流——苏晚的第一桶金。一份未签完的矿权协议——孟慧的旧案。最后一行是禁令。

他安排后事的对象选择，本身就是一张网：把表给何钟（物证保管）、把合同给陆况（利益博弈）、把陪护给顾言（情感牵连）。他不是在安排后事，是在安排一张"死后还能运转的网"。

他声音洪亮、坐姿端正如钟。说一不二。对"规矩"两个字有执念——但他请十六个人来，正是为了把规矩表最后一行的禁令亲手打破。

他要宣布的"大事"，是 2007 年的真相。

他没能宣布。

她这次回猎庄，是来准备那顿"最丰盛的一顿"的——但庄主没等到那顿饭。

# 阿禾（ISFJ · 守卫者）

# 秋月（ESFP · 表演者）

父亲年轻时在猎庄唱过《三更雨》。父亲临终前告诉她："猎庄那台戏，唱完之后有人改了戏词。"她一直没懂，直到她在后台旧箱子里翻到一页改过的戏词——字迹是老庄主的。戏词里藏着一句"给懂的人的话"。

手机里有段彩排录像，画质极差，只有她自己能看清。录像里，本该空着的后台，多了一个不该有的人——那个人不是戏班的，是猎庄的。她认出了那个人，但没对任何人说过。

她这次来，是来唱今年这台戏。剧本里那出《三更雨》，她准备按"改过的戏词"唱——因为"庄主改了戏词，是想让某些话从戏里说出来"。

她永远在笑、在唱、在暖场。被问及《三更雨》时先说"那出戏不吉利"——但她的眼睛会微微亮一下，像一个藏着秘密的人终于被人提到了秘密的入口。对"后台"和"录像"有回避。卸妆时永远最后一个走。

她知道林一在拍《十三》——她酒友的那组照片，她没说破。她知道庄主改了戏词——她准备唱出来。她知道后台录像里那个人是谁——但她要等一个"合适的时候"说出来。

她这次回猎庄，是来唱一台戏的——但她唱的不只是戏。
