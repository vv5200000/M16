# M16 · 一案的 16 段人生（MBTI 罪案互动叙事）

> **一句话定位**：一部第三人称互动刑侦中篇——16 个性格鲜明的人物因一桩案子产生交集；读者以旁观+导播/评审的方式参与，不同读者看到不同的故事组合，读完被告知"你在全程被测 MBTI"并收到自己的结果。
>
> **项目代号**：M16（16 型人格 × 一个案件）。

## 四条铁律

1. **吸引读者优先**——最优先的目标是让读者从头到尾读完。
2. **测量让路**——隐形测 MBTI 其次，不追求客观测准。
3. **事后告知**——读者全程不自知；全部完成后告知并交付结果。
4. **16 是卡司，不是凶手配额**——16 个人格以鲜活人物出现，不强行当凶手。

---

## 核心架构

- **后台 · 档案库**：16 份人物模块（16 个人格画像档案袋），每人独立故事线。**永远不出现在前台**。
- **后台 · 主线逻辑**：第 17 条主故事线 + 3–5 个定罪原型 + 嫌疑累计规则。
- **前台 · 叙事**：一条连续无缝、由情节推进的故事。读者永远看不到"16 选 1"，只有剧情内的自然决策（跟哪条线 / 审问谁 / 信不信谁）。
- **读者身份**：第三人称旁观 + 导播/评审（读者是"冷案档案员"）。
- **多结局**：凶手/真相不唯一（3–5 个定罪原型），由读者路径实时塑造，结局"定罪"决策点落定。
- **测量映射**：S/N（查细节 vs 查动机）、T/F（信理性 vs 信情感）、E/I（广撒网 vs 深挖）、J/P（早收网 vs 反复重查）——**个性化本身就是测试**。
