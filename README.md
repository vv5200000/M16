# M16 · MBTI 罪案侧写互动叙事

> **一句话定位**：一部"章回可玩"的互动刑侦小说——读者不写 MBTI 测试题，而是在破案抉择中，被自己的决策模式测出真实的人格内核。
>
> **项目代号**：M16（16 型人格 / 16 个凶手 / 十六格木盒 / 结案编号到"十七"）。

---

## 核心理念

基于"**MBTI 先天内核不变，后天行为可变**"的逻辑，绕过"做题测试"，改用"**刑侦破案投射**"记录读者真实的决策偏好。

- 读者只见"社会面具（后天行为）"，故事揭露"最深处的秘密（先天内核）"。
- 不做标准答案：每条破案路径都能通向真相，测的是**你的方法偏好**，不是你有没有破对案。
- 故事容器：暴风雪山庄 + 单元剧连环案 + 互动抉择。

---

## 关键设计支柱

1. **关键词无痕投射**——不出现任何选择题/按钮，读者自由输入关键词探索场景，在完全不知情下完成行为采样。
2. **隐性分叉**——关键时刻无按钮，读者输入被系统后台分类为决策一端（行动分叉 E/I · 干预分叉 T/F · 收束分叉 J/P），叙事线性收束、数据落库。
3. **渐进式出结果**——不必做完16案；每个维度采样达标即逐度解锁（详见 `design/交互机制设计.md`）。
4. **四幕节奏**——立威→诛心→内乱→归零，16个凶手分四幕布局，幕末设阶段性报告。

> **双通道口径（2026-08-03 统一）**：感知层（S/N）走关键词探索；决策层（T/F、E/I、J/P）走隐性分叉。一维一信号源，禁止跨层混算。
> 规格见 `design/关键词交互_无痕投射_技术规格与实现方案.md`；第一案见 `cases/第一案_猎杀营_关键词重构版.md`。
