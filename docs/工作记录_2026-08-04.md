## 二、技术细节

### 2.1 CloudBase 上报机制

```
用户输入 → pushLog → submitEntry → syncQueue.push → saveQueue（localStorage）
→ pump() → ensureCb() → cloudbase.init → signInAnonymously → db.collection().add()
→ 成功则 shift 队列，失败则 unshift 回队列重试
```
