# M16 · 项目规划 v2（2026-08-15 重构）

> 本文档替代旧方案（`ROADMAP.md` 中的"16 案 × 16 凶手"架构），是当前唯一有效的规划基线。
> 状态标记：⬜ 待做 / 🔄 进行中 / ✅ 完成

---

## 一、架构转向背景（为什么要 v2）

旧方案把「16 个凶手 = 16 种人格」一一绑定，产生三大死结：

1. **不是所有类型都能撑起"凶手"角色**（ISFJ/ESFJ 当凶手很别扭）——16 个人格被迫承担同一职业标签。
2. **16 个独立案件 = 巨大的写作与产能压力**，且模式雷同、读者疲劳。
3. **结构暴露边界**：读者一旦猜出"一章=一人格"，就会逆向破解测试，原则 3（不自知）崩坏。

v2 的全部设计都围绕解开这三根绳展开。

---

## 二、四条铁律（本项目优先级，永不被推翻）

1. **吸引读者优先**：最优先的目标是让读者从头到尾有兴趣读完。
2. **测量让路**：兴趣问题解决后，隐形测 MBTI 的功能再考虑；测量不需要"客观测准"。
3. **事后告知**：读者被吸引读完的过程中不自知是在测 MBTI；全部完成后，必须告知并交付测量结果。
4. **16 是卡司，不是凶手配额**：16 个人格以"鲜活人物"出现，不强行担任凶手。

---

## 三、v2 核心架构

### 3.1 一句话定位

> **一个案件的 16 段人生**：16 个性格各异的人，因第 17 条主故事线（一桩案子）产生交集；读者以第三人称旁观+导播/评审参与，不同读者看到不同的故事组合，结尾获得基于自身选择的 MBTI 结果。

### 3.2 两层结构：前台 / 后台

| 层 | 内容 | 可见性 |
|---|---|---|
| **后台 · 档案库** | 16 份人物模块（= 16 个人格画像档案袋），每人独立故事线 | **永远不可见**，是数据结构名词，不是前台故事元素 |
| **后台 · 主线逻辑** | 第 17 条主故事线 + 3–5 个定罪原型 + 嫌疑累计规则 | 不可见 |
| **前台 · 叙事** | 一条连续、无缝、由情节推进的故事 | 读者只看到情节，永远看不到"16 个选项/菜单" |

**核心原则**：前台永不出现"16 选 1"。读者的选择永远是**剧情内的自然决策**（跟哪条线、审问谁、信不信谁），后台据此加载对应人物模块。读者只觉得"我选了这条线所以遇见了这个人"。

### 3.3 读者身份（第三人称）

- 读者**不扮演第一人称角色**，避免"角色性格 vs 读者本性"冲突污染测量。
- 形态：**旁观 + 导播/评审**——读者看谁的戏份久、信谁的话、跟谁的线索走，这些注意力分配就是测量信号。
- 戏内免费容器：读者是"冷案档案员"——在整理一份案件的十六段人生来破案。

### 3.4 测量映射（一维一信号源，禁止混算）

| MBTI 维度 | 信号来源（读者行为） |
|---|---|
| S / N | 主动拉取"细节证据"还是"动机因果" |
| T / F | 信"理性冷"型角色还是"情感热"型角色 |
| E / I | 广撒网见多人 vs 深挖几个人；是否高调出手 |
| J / P | 早收网下结论 vs 反复推翻重查 |

> 个性化本身就是测试：读者看到的故事组合 = 他的选择；他的选择 = 全套 MBTI 信号。因结构不可见，读者想"作弊"都无门。

### 3.5 多结局（3–5 个真相）

- 凶手/真相**不唯一**，3–5 个定罪原型：
  - 版本A = 情绪背叛型（F 向：为情/为恨）
  - 版本B = 冷算布局型（T 向：为利/为局）
  - 版本C = 冲动误杀型（意外失控后掩盖）
  - （可扩至 5 版，先做 3 版验证）
- **规则**：凶手由读者的"走位"（路径累计的嫌疑分数）实时塑造，在结局的"定罪"决策点落定。
- **防内容爆炸**：模块文本中立（不预设真凶）；结局共享骨架、局部变化（被捕者/收束文案不同）。
- **防类型期待破灭**：开场承诺"查出发生了什么"，不承诺"唯一解"；"为何有多个版本"留到结局揭晓。
- **防瞎猜**：每个候选凶手在定罪那一刻都值得怀疑——2–3 个给足证据线，其余作"阴影"。

### 3.6 生产模型（反转）

- 每个读者的实际体验 ≈ 主干 + 4–8 份模块 ≈ **短篇体量**
- 全库 16 份模块 + 主干 = **中篇素材**（6–10 万字）
- **不必写完 16 份才能上线**：主干 + 4–6 份模块即可发布 v1，之后每补一份模块 = 一次内容更新（"连载"从写第 N 案变成加一个人）。

---

## 四、写作顺序（重要）

**先定"定罪原型"，写人时把标签焊进去**，避免先写满 16 再贴标签导致返工。

1. **阶段① · 案件契约（一页纸）**：案件设定 + 3 个定罪原型（"哪种人"，不是"谁"）+ 嫌疑累计规则。
2. **阶段② · 16 个模块**（对照契约写）：每人 = 人格画像 + 与案件关系 + 证据碎片 + 决策点 + 嫌疑标签。带"主嫌疑"标签的 3–5 人和案件连接要格外密，其余可松（控制工作量）。
3. **阶段③ · 第 17 条主故事**：按模块挂钩，把读者带进 16 段人生交织，收束在"定罪"决策点。
