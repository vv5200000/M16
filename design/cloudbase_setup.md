## 二、CloudBase 控制台步骤

### 1. 新建环境
1. 登录 https://console.cloud.tencent.com/tcb
2. 首次使用 → 创建环境：环境名称如 `m16`，**计费方式选「免费额度/按量」**，地域可选（大陆默认即可）。
3. 等待环境初始化（约 1-2 分钟）。记下 **环境ID**（形如 `m16-xxxxxxxx`）。

### 2. 开启匿名登录
控制台 → 左侧 **身份认证 → 登录设置** → 勾选 **匿名登录** → 保存。

### 3. 建数据库集合
左侧 **云数据库** → 新建集合 → 集合名 **`case1_submissions`**（必须完全一致）。
> 权限保持默认「仅创建者可读写」即可：每个匿名用户只能写自己的记录、读不了别人的，测试者互不可见，安全。

### 4. 配置 Web 安全域名
左侧 **环境 → 安全设置（或「Web 安全域名」）** → 添加：
- 你将要部署的静态托管域名（形如 `m16-xxxx.tcloudbaseapp.com`）
- 本地调试若需要：`http://localhost:8080` 之类

> 匿名登录 + 安全域名未配好时，上报会失败（控制台 console 报「匿名登录失败/未授权域名」），日志会进入待传队列持久化，配好后自动补传。

### 5. 把环境 ID 填进 HTML
编辑 `prototypes/第一案_猎杀营.html` 顶部：
```js
const CLOUDBASE = {
  env: "m16-xxxxxxxx",   // ← 你的环境ID
  ...
};
```

## 三、部署（静态托管）

1. 控制台 → **静态网站托管** → 首次使用需开通（免费）。
2. 上传文件：拖入 `prototypes/第一案_猎杀营.html`。
3. 部署完成后复制「默认域名」：`https://m16-xxxx.tcloudbaseapp.com` —— **把这个链接发给测试者**。

> 重新部署：改过 HTML 后，回到静态托管重新上传同名文件覆盖即可，链接不变。

## 四、验证

1. 本地先测：若加了 `http://localhost` 安全域名，可用 `npx serve` 起本地服务测上报；
   或直接打开线上链接测。
2. 打开页面玩几处 → 控制台 **云数据库 → case1_submissions**，应看到行在增加。
3. 开发者面板（页面底部）会显示 **"● CloudBase 收集已开启 · 待传 0"**。

## 六、常见问题

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 控制台报「not allowed to call this function」 | 匿名登录未开 或 安全域名未加 | 见 §二.2 / §二.4 |
| 页面打开但日志不进库 | env 没填 / 填错 | 检查 `CLOUDBASE.env` |
| 待传数字一直不降 | 网络或权限问题，队列持久化中 | 修好后自动补传；仍失败可看 console |
| 想彻底重新测试 | — | 页面开发者面板 → 重置；或清 `localStorage` |
