# M16 · 人物模块模板

> 一人一文件 → `cases/modules/<姓名>.md`。依据：`cases/案件契约_v1.md`（字段冲突以契约为准）。
> 后台档案库，前台永不可见结构；若文本显真凶，三版全毁。

```markdown
# <姓名>（<MBTI> · <类型中文名>）

## 画像
- 年龄 / 职业 / 与猎庄关系（一句话）
- 鲜明行为 2–3 条（前台可见，人格藏在行为里，不点破）

## 与案件关系
- 旧案碎片：<他/她掌握哪段旧案>
- 当晚机会/动机：<为什么当晚在、能做什么>

## 证据碎片
| 碎片 | 指向 | 归属路径 |
|---|---|---|
| <可被读者直接观察的事实> | A/B/C 无/弱/强 | 证物·链名（车/枪线·时间窗口线·现金流线·日记信线） |
| ... | | |

> 至少 1 条"可被两种原型解释"的碎片（防标签化反转）。

## 决策点（读者在戏内会遇到的自然选择）
| 场景 | 选项 A | 选项 B | 计分流向 |
|---|---|---|---|
| <前台某情节节点> | <戏内自然的做法> | <另一做法> | A/B/C 各 +N |
| ... | | | |

> 选项必须戏内自然（跟谁谈、信不信、查哪条线），禁止"你怀疑谁"菜单。

## 嫌疑标签
- <主嫌疑 A/B/C · 主入口 / 候选 / 证人 · 物证>
- 反转余地：<一句话，若作为假结局如何翻>
```

## 写作铁律
1. 文本中立：模块不预设真凶，证据只加重嫌疑方向，不给唯一解。
2. 前台连续叙事：无"第 N 号人物"字样、无编号、无"可选人选"结构。
3. 决策点计分 = 读者注意力分配（见 `docs/项目规划_v2.md` §3.4）。
4. 证据碎片必须全部来自 `cases/v2_16人物故事线.md` 已确认事实，本模块只做切分与标注，不新增设定。
