## 一、渐进式出结果（无需做完 16 案）✅

MBTI 是 4 组二元维度（E/I、S/N、T/F、J/P），每组维度按"**采样达标即逐度解锁**"，不是"全部做完才给结果"。

| 进度 | 数据量 | 产出 |
| :--- | :--- | :--- |
| 第 3 案 | 已覆盖 3-4 个维度 | 初始倾向（置信度最高的 1-2 个维度） |
| 第 8 案 | 每维度 ≥3 次采样 | 中间画像（4 字母倾向 + 各维度置信度条） |
| 第 12 案 | 采样饱和 | 高置信画像（接近终版） |
| 第 16 案 | 16 组完整切片 | 终版：八维雷达图 + 类型解读卡 |

关键：**各维度填充速度不同**。有的读者 3 案就锁定 S/N，有的到第 10 案 F/T 还在摇摆。因此是"逐维度达标即出"，而非"全做完才出"。

**配套叙事**：每幕（4 案）结束给一次阶段性报告 → 制造坚持到下一幕的动力。✅

## 二、16 凶手 ≠ 16 个独立完整案 ✅

读者的人格是从**决策行为**读出的，不是从"匹配了哪个凶手的办案风格"读出的。16 个凶手是为服务**叙事谜面与"十六格木盒"终极真相**，不等于要做 16 篇独立长篇。

### 幕内密度分层（每 4 案）

| 类型 | 每幕搭配 | 功能 |
| :--- | :--- | :--- |
| 主轴案 ×1 | 深度长篇，双抉择 + 反转 | 推主线、回收木盒格槽 |
| 复用案 ×2~3 | 同骨架换变量 | 集齐维度采样、填充节奏 |
| 急转案 ×1 | 快节奏迷你案 | 提情绪、卡高能反转 |

> 独立写作量约为"1.5 个案"，但 16 个格槽照常推进。✅

**可选进一步收敛** ❓：允许一个凶手横跨多个现场（不同塔罗牌），16 格去重、戏剧浓度更高、写作再砍。

## 三、交互机制：感知层 × 决策层（双通道）✅

**正式交互形态 = 关键词无痕投射（感知层）+ 隐性分叉（决策层）。**
显式按钮已废弃，但"抉择采样"未废弃——只是按钮隐形、数据照记、叙事线性收束。
完整规格见 `design/关键词交互_无痕投射_技术规格与实现方案.md`；第一案落地见 `cases/第一案_猎杀营_关键词重构版.md`。

| 通道 | 采样内容 | 负责维度 | 机制 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| 感知层 | 关注/忽略/顺序/停留 | **S / N** | 关键词自由探索 | ✅ 已实现（第一案） |
| 决策层 · 行动分叉 | 独行 vs 集队 | **E / I** | 隐性分叉（无按钮） | ✅ 已实现，待验证 |
| 决策层 · 干预分叉 | 任务 vs 救人 | **T / F** | 隐性分叉（无按钮） | ✅ 已实现，待验证 |
| 决策层 · 收束分叉 | 速断 vs 多解 | **J / P** | 隐性分叉（无按钮） | ✅ 已实现，待验证 |

> **铁律（一维一信号源）**：S/N 只走感知层；T/F、E/I、J/P 只走决策层隐性分叉。禁止从关键词输入反推 E/I、J/P，避免双重计数污染雷达图。
> 显式三岔口（A/B/C）已由感知层 + 隐性分叉取代，旧分叉版第一案存档于 `cases/第一案_猎杀营_分叉版_superseded.md`。

## 四、关键产品原则

1. **正确凶手唯一，但路径可并行**：测的是"方法偏好"，不是"破案对错"，避免选错挫败。
2. **每个选择都有真实代价**：不做"选 T 就赢、选 F 就输"。例：第一案 T 赢案但背疚，F 救人但案悬。✅ 隐性分叉下代价以"收束回响"呈现（叙事线性，回响不同）。
3. **不要教育读者**：展示"每一把刀都有它的刃和背"，而非"INTJ 很坏 / INFP 很弱"。
4. **游戏优先于小说**：文字先服务互动——每个高潮处即一处隐性分叉（读者输入即触发，无按钮）。
